# ===========================================================================
# 插件清单 —— 90% 的改动都只发生在这个文件里
#
# 语法（比手写 CONFIG_PACKAGE_xxx=y 简单得多）：
#   每行一个包名，可以带空格和注释
#   行首加 ! 表示「显式关掉」（对应 .config 里的 "# CONFIG_PACKAGE_x is not set"）
#   以 # 开头是注释，整行忽略
#   名字就是 opkg/apk 里的包名，也是 feeds 里目录名：luci-app-xxx / kmod-xxx / 本体名
#
# 改完直接点 Actions → Run workflow 就行，脚本会自动拼成 openwrt/.config，
# 并在编译前用 5 秒告诉你「这些包在 feed 里找不到」，不用等 1 小时 45 分。
# ===========================================================================

luci-app-openclash

# ----- 去广告 + DNS -----
# 本体在 packages feed，LuCI 界面在 luci feed，两个都要
luci-app-adguardhome
adguardhome

# ----- 网络加速（= 老的 TurboACC 那几个开关，上游已并入「防火墙」页面）-----
# 2026-10-29 上游把 luci-app-turboacc 从 luci@openwrt-25.12 移除了：全锥形 NAT、
# TCP 拥塞控制、流量卸载都搬进了 LuCI → 网络 → 防火墙 → 常规设置。
# 页面上那几项「看不看得见」取决于固件里有没有对应内核模块（LuCI 靠 /sys/module/<名> 探测）：
#   kmod-nft-fullcone   启用 FullCone NAT（FULLCONENAT / Broadcom Fullcone NAT1）
#   kmod-nft-offload    软件流量卸载（Flow Offloading）
#   kmod-tcp-bbr        TCP CCA 里的 bbr
# 默认值（全锥 NAT + 软件卸载 + bbr）由 files/etc/uci-defaults/99-turboacc 写进去。
kmod-nft-fullcone
kmod-nft-offload
kmod-tcp-bbr

# ----- 虚拟化网卡 -----
# PVE 用 VirtIO 网卡时需要；若内核已内建，这一行会被 defconfig 丢弃，属正常
kmod-virtio-net

# ----- 显式关闭 -----
# lede 的 DEFAULT_PACKAGES.router 默认带 ssr-plus，会和 openclash 抢 DNS/端口
!luci-app-ssr-plus

# iStore 应用商店：暂时不要（2026-11 实测 lede master 的 DEFAULT_PACKAGES.router 里并没有它，
# 这里显式关掉是保险：哪天上游把它塞进默认包、或者你从 extra_packages 里带进来，都会被这行挡住。
# 包名不存在时预检会把它列在「已请求关闭、但 feed 里本来就没有」里，属正常，忽略即可）
!luci-app-store
